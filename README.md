# DnepritLoyalty

Програма лояльності та внутрішній бонусний рахунок для **MODX Revolution 2.8.1 + miniShop2**. Компонент використовує стандартних `modUser`, тому сумісний з **Office** як особистим кабінетом та системою авторизації.

## 0.1.0-beta3

Beta3 додає перший окремий етап інтеграції з Office: синхронізацію вже існуючих покупців з вибраних груп MODX у бонусні рахунки DnepritLoyalty.

У вкладці **Клієнти** з'являється кнопка:

```text
Синхронізувати клієнтів Office
```

Синхронізація:

- читає ID груп із `dnepritloyalty.allowed_groups`;
- знаходить учасників цих груп через `modUserGroupMember`;
- створює по одному `DnepritLoyaltyAccount` на `modUser.id`;
- не створює дублі при повторному запуску;
- не зачіпає адміністраторів та інших користувачів, якщо їх групи не вказані;
- не перераховує старі замовлення та не нараховує бонуси на цьому етапі;
- показує підсумок: знайдено / створено / вже існувало / помилки.

Для поточного магазину Office-клієнти знаходяться у групі:

```text
Users = 1000000000
```

Тому в налаштуванні використовується:

```text
dnepritloyalty.allowed_groups = 1000000000
```

### miniShop2 статуси поточного магазину

```text
dnepritloyalty.lifetime_statuses = 2,3
dnepritloyalty.reward_statuses   = 2,3
dnepritloyalty.cancel_statuses   = 4,1001
```

Поки перевіряється синхронізація клієнтів, програму лояльності та оплату бонусами рекомендується залишити вимкненими.

Пакет:

```text
dnepritloyalty-0.1.0-beta3.transport.zip
```

## Архітектура

```text
modUser
   ↓
Office — авторизація / профіль / особистий кабінет
   ↓
miniShop2 — кошик / checkout / замовлення
   ↓
DnepritLoyalty
   ├─ бонусний рахунок
   ├─ резерв бонусів
   ├─ історія операцій
   ├─ Lifetime сума покупок
   ├─ рівень клієнта
   └─ постійна знижка
```

DnepritLoyalty не створює окремих користувачів і не дублює авторизацію Office. Ключ зв'язку — `modUser.id` / `msOrder.user_id`.

## Основний функціонал

- внутрішній бонусний рахунок авторизованого покупця;
- доступний та зарезервований баланс;
- незмінна історія операцій;
- ручне нарахування / списання менеджером;
- бонуси за реєстрацію та перше оплачене замовлення;
- нарахування відсотка від замовлення;
- резерв бонусів під час оформлення та повернення при скасуванні;
- захист від подвійного нарахування через `unique_key`;
- рівні Lifetime Discount за сумою сплачених замовлень;
- процентна або фіксована постійна знижка;
- вибір статусів замовлень для Lifetime-розрахунку;
- період Lifetime від / до;
- обмеження за групами користувачів;
- мінімальна сума поточного замовлення;
- ліміт частки замовлення, яку можна оплатити бонусами;
- CMP: Клієнти, Операції, Рівні, Правила, Налаштування;
- snippets для балансу, кабінету та checkout;
- підготовлена інтеграція `OnDnepritNewsletterSubscribe`.

## Установка

Transport-пакет встановлюється через стандартний **Extras → Installer** MODX. Beta3 можна встановлювати поверх beta2 без видалення компонента та його даних.

Залежність: встановлений miniShop2.

## Checkout

Після окремого етапу тестування checkout всередину форми miniShop2 можна буде додати:

```modx
[[!DnepritLoyaltyCart]]
```

На етапі beta3 підключати списання бонусів у бойове оформлення ще не потрібно.

## Office / особистий кабінет

Компонент уже працює з тим самим `modUser`, який використовує Office. Для майбутнього виводу в кабінеті передбачені:

```modx
[[!DnepritLoyaltyBalance]]
[[!DnepritLoyaltyAccount]]
```

## Lifetime Discount

Рівні задаються у CMP, наприклад:

```text
5 000 грн  → 3%
15 000 грн → 5%
30 000 грн → 7%
70 000 грн → 10%
```

## Безпека обліку

Кожна зміна бонусного балансу має окрему транзакцію. Системні операції використовують унікальні ключі на кшталт:

```text
rule:registration:42
rule:first_order:42
order_reward:1555
order_spend:1555
```

Повторна обробка тієї самої події не повинна створювати повторне нарахування.

## Резерв бонусів

Якщо створення замовлення перерветься після резервування, резерв має TTL 30 хвилин. Рекомендований cron раз на 5 хвилин:

```cron
*/5 * * * * /usr/bin/php /path/to/site/core/components/dnepritloyalty/cron/release-reservations.php
```
